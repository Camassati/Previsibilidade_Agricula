------------------------------------------------------------------------------

  quando NÃO há histórico do município (esquema espacial). O ganho sobre o
  método tradicional ingênuo é de ~9,5%; sobre a linha de base bem
  especificada (média indexada pelo ano) cai para ~3,0%.

  Em previsão de safra ainda não iniciada (esquema temporal) o modelo PERDE
  para o método tradicional. Cinco safras não bastam para aprender a dinâmica
  interanual: há 145 municípios para generalizar no espaço, mas apenas quatro
  transições de safra para generalizar no tempo.

  O maior coeficiente do modelo não é climático: é base_hist, a média
  histórica do próprio município. O modelo aprende primeiro ONDE está, e só
  depois COMO foi o ano.

  Conclusão delimitada: a ferramenta serve para acompanhar a safra em curso,
  não para projetar safras futuras.
